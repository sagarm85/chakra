Build a simple URL shortener REST API in Python.

The API needs to:
1. POST /shorten — accept a long URL and return a short code (6-char alphanumeric)
2. GET /{code} — redirect to the original URL (302), or return 404 if code not found
3. GET /stats/{code} — return the original URL and how many times it has been accessed

Requirements:
- Store data in memory (a Python dict is fine, no database needed)
- Use Flask or FastAPI
- Return JSON for all non-redirect responses
- Include basic input validation (reject empty or non-URL strings)
